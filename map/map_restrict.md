## 功能一：路径点击 → 约束生成

### 1.1 核心思想

用户在 SVG 海图上**点击一条完整路径**（如 出击点 → A → E），系统将该路径拆分为若干条边，对每条边查询节点规则表，提取"达成目标方向"的所有概率档次。用户为每条边选择一个概率档次后，系统通过**约束合取**与**冲突检测**，输出最终可行的舰队编成模板。

### 1.2 路径拆分与概率档次提取

以路径 **出击点 → A → E** 为例：

**边①：出击点 → A**

查规则表，筛选目标为 A 的条目，按概率分档：

| 概率档次 | 约束配方 |
|:---|:---|
| 100% | 船数 ≤ 5 且 DD + DE = 4 |
| 70% | 船数 = 1~3 |
| 60% | 船数 = 4 |
| 50% | 船数 = 5 |
| 40% | 船数 = 6 |

**边②：A → E**

查 A 点规则，筛选目标为 E 且概率符合用户要求的条目。假设用户要求 100%，则提取所有 100% 到 E 的配方：

| 编号 | 约束配方 |
|:---|:---|
| α | 高速以上 |
| β | DD + DE = 6 |
| γ | CL + CT = 1 且 DD + DE = 5 |
| δ | CL = 1 且 DD = 4 |

### 1.3 并集与交集的数学结构

**单节点内部：并集（∪）**

同一节点、同一概率水平下，多个配方之间是"或"关系。满足任一配方，即可达成该概率。

> 例：A 点 100% 到 E，满足 α 或 β 或 γ 或 δ 均可。

**跨节点之间：交集（∩）**

路径上所有边的约束必须同时成立。总可行区域是各节点选择集的交集。

> 例：边①约束 C₁ 与边②配方 R 的交集为 C₁ ∩ R。

**分配律展开**

总可行区域 = C₁ ∩ (R_α ∪ R_β ∪ R_γ ∪ R_δ)
            = (C₁ ∩ R_α) ∪ (C₁ ∩ R_β) ∪ (C₁ ∩ R_γ) ∪ (C₁ ∩ R_δ)

系统逐个检查每个子交集是否为空（是否冲突），只保留非空的可行方案。

### 1.4 冲突检测与方案过滤

系统对每种配方组合做约束合取，检测典型冲突模式：

| 冲突类型 | 例子 | 结果 |
|:---|:---|:---|
| 等式矛盾 | DD+DE=4 与 DD+DE=6 | 不可行 |
| 范围矛盾 | 船数≤3 与 DD+DE=6 | 不可行（装不下）|
| 存在性矛盾 | 需CL=1 与 已选6艘无CL位 | 不可行 |

冲突的方案被过滤，可行的方案保留并展示。

### 1.5 路径先验约束：舰种过滤

**核心原则：路径一旦选定，可行空间即锁死。**

系统从所有可行配方的并集中，提取**出现过的舰种集合**，作为该路径下允许选择的舰种。未出现的舰种**直接不在界面中展示**，而非"展示但禁用"。

**示例**

路径 出击点 → A → E（100%）的可行配方：
- 配方X：船数=5，DD=4，CL=1
- 配方Y：船数≤5，DD+DE=4，全高速

允许舰种 = {DD, CL, DE, 高速BB, 高速CA, 高速CL...}

不允许舰种 = {CV, CVL, SS, AV, 低速BB...} → **直接隐藏**

### 1.6 约束传播：数量调整的动态联动

用户在允许的舰种范围内调整数量，系统实时执行**约束传播（Constraint Propagation）**：

**维护状态**
- 当前已选舰种计数
- 剩余可行配方集（初始为路径所有可行配方）

**每次操作后的传播逻辑**
1. 更新当前状态
2. 过滤剩余可行配方集：检查每个配方是否仍可能被满足
3. 若某个配方被排除，从候选集中移除
4. 根据剩余配方的并集，重新计算各舰种的+/-按钮状态
5. 若剩余配方唯一确定，锁定全部数量，不可再调

**按钮状态语义**
- **绿色高亮**：剩余所有可行配方都需要此舰种（强烈建议）
- **白色可用**：部分可行配方允许此舰种（可选）
- **灰色禁用**：当前状态下选择此舰种会导致所有配方不可行
- **红色警告**：已选数量超出任何配方的允许范围

**示例推演**

状态：DD=4，其他=0
- 配方X（DD=4, CL=1, 船数=5）：DD已满足，还需CL=1
- 配方Y（DD+DE=4, 全高速）：DD+DE=4已满足（DE=0），第5艘需高速

系统推断：
- DE的+禁用（DD已是4，加DE会让DD+DE>4）
- CL的+可用（配方X需要）
- 高速CA/CL的+可用（配方Y允许作为第5艘）
- BB/CV的+禁用（两个配方都不允许）

状态：DD=4, CL=1，合计=5
- 配方X：完全满足
- 配方Y：若CL为低速，则"全高速"不满足，配方Y被排除

系统锁定：
- 唯一配方确定为X
- DD锁定在4，CL锁定在1
- 其他所有舰种+禁用
- 总船数锁定在5

### 1.7 死胡同与回退

若用户操作导致剩余可行配方集为空（走入死胡同），系统立即提示：

> ⚠️ 当前选择无法达成目标路径的任何可行配方。
> 建议：撤销某步操作，或切换为更低概率档次。

提供"重置"按钮，清零所有选择，恢复初始候选集。

### 1.8 与舰船库、舰队栏的联动

**三层界面联动结构**

| 区域 | 功能 | 约束来源 |
|:---|:---|:---|
| 左侧：舰种数量选择器 | 调整各舰种数量 | 路径先验过滤 + 约束传播 |
| 中间：舰船库 | 从已有舰娘中点选具体船只 | 左侧数量上限 + 舰种过滤 |
| 右侧：舰队栏 | 显示最终编成，可拖拽排序 | 总船数约束 + 旗舰位约束 |

**联动逻辑**
- 左侧数量确定后，中间舰船库自动切换到对应舰种标签页
- 某舰种数量选满后，该标签页显示"已选满"
- 右侧舰队栏槽位数由总船数约束决定（如船数=5则5个槽）
- 拖拽排序时实时校验位置约束（如"旗舰需为CL"）

## 功能二：编成给定 → 路径推演

用户在右侧面板配好舰队编成，系统在海图上正向推演所有可能路径，并标注每条边的概率。

### 2.1 特征提取

从编成中提取三类特征：
- 总船数 n ∈ [1,6]
- 舰种存在性（有无某类舰种）
- 舰种计数（各类舰种各几艘）

### 2.2 逐节点概率计算

从起点开始，对每个节点：
1. 用当前编成特征匹配该节点的规则表
2. 按优先级从高到低检查固定分支、概率分支、兜底随机
3. 计算每个出口的概率
4. 在海图对应边上标注概率值、着色

### 2.3 路径提取与总概率

从概率树中提取所有"根到叶"路径：
- 单条路径概率 = 路径上各边概率的乘积
- 到达目标节点的总概率 = 所有通往该目标的路径概率之和

### 2.4 海图视觉标注

| 概率范围 | 线条样式 | 含义 |
|:---|:---|:---|
| 100% | 绿色粗实线 | 确定可达 |
| 60%~99% | 黄色虚线 | 高概率可达 |
| 20%~59% | 橙色细虚线 | 低概率，看脸 |
| <20% | 红色细线 | 几乎不可达 |
| 0% | 灰色 | 当前编成下不可达 |

侧边栏列出所有可达路径及其总概率、期望战斗次数。

## 附录：约束类型汇总

| 类型 | 数学形式 | 示例 |
|:---|:---|:---|
| 总船数 | size = k / size ≤ k / size ≥ k | 船数=5，船数≤5 |
| 舰种存在 | type ∈ fleet / type ∉ fleet | 必须有CL，不可有CV |
| 舰种计数 | count(type_set) op value | DD=4，DD+DE≤4，CL≥1 |
| 旗舰约束 | flagship_type = T | 旗舰必须是CL |
| 速力约束 | fleet_speed ≥ threshold | 全高速以上 |

## 附录：术语对照

| 术语 | 含义 |
|:---|:---|
| 配方 | 单条规则条目对应的完整约束组合 |
| 选择集 | 某节点某概率下所有配方的并集 |
| 约束传播 | 根据当前选择实时缩小剩余可行空间 |
| 路径先验 | 路径确定后立即过滤不允许的舰种 |
| 正向推演 | 给定编成，计算可达路径与概率 |
| 反向求解 | 给定路径，反推所需编成约束 |
