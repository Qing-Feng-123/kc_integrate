## 功能一：路径点击 → 约束生成

### 1.1 核心思想

用户在 SVG 海图上**点击一条完整路径**（如 出击点 → A → E），系统将该路径拆分为若干条边。对每条边，用户设置一个**最低概率阈值 θ**（范围 0%~100%），系统保留该边上所有概率 ≥ θ 的配方进入候选池。最终通过**约束合取**与**冲突检测**，输出可行的舰队编成模板。

**关键特性**：阈值是连续可调的。用户把阈值调高，约束变严格、方案变少；把阈值调低，约束放宽、方案变多。最低可设为 0%，此时该边的全部配方均进入候选。

### 1.2 路径拆分与阈值过滤

以路径 **出击点 → A → E** 为例：

**边①：出击点 → A**

查规则表，该边所有配方按概率从高到低排列：

| 概率 | 约束配方 |
|:---|:---|
| 100% | 船数 ≤ 5 且 DD + DE = 4 |
| 70% | 船数 = 1~3 |
| 60% | 船数 = 4 |
| 50% | 船数 = 5 |
| 40% | 船数 = 6 |

用户为此边设置阈值 θ₁。系统保留所有概率 ≥ θ₁ 的配方：

| 用户设 θ₁ | 保留的配方 | 说明 |
|:---|:---|:---|
| 100% | 仅 100% 配方 | 最严格，唯一解 |
| 70% | 100%、70% | 放宽一档 |
| 40% | 全部配方 | 最宽松，全部进入候选 |
| 0% | 全部配方 | 等同最低非零概率档 |

**边②：A → E**

查 A 点规则，筛选目标为 E 的全部配方：

| 概率 | 约束配方 |
|:---|:---|
| 100% | 高速以上 |
| 100% | DD + DE = 6 |
| 100% | CL + CT = 1 且 DD + DE = 5 |
| 100% | CL = 1 且 DD = 4 |
| 65% | 兜底随机（直接到 E）|

用户设阈值 θ₂，系统保留概率 ≥ θ₂ 且目标为 E 的配方。

**总概率下限**：系统实时计算并展示

$$P_{total} = \prod_{i} \theta_i$$

或更精确地，对具体配方组合计算乘积。界面用颜色警示：
- ≥80%：绿色（高稳）
- 50%~80%：黄色（可接受）
- <50%：红色（看脸）

### 1.3 并集与交集的数学结构

**单节点内部：阈值决定并集范围（∪）**

同一节点、同一阈值下，保留的多个配方之间是"或"关系。满足任一保留配方，即可达成该边在该阈值下的最低要求。

> 例：边②设阈值 65%，保留 4 个 100% 配方 + 1 个 65% 兜底配方。满足其中任一即可。

**跨节点之间：交集（∩）**

路径上所有保留配方的约束必须同时成立。总可行区域是各边候选集的交集。

**分配律展开**

设边①保留配方集为 $R_1 = \{r_{1a}, r_{1b}, \ldots\}$，边②保留配方集为 $R_2 = \{r_{2a}, r_{2b}, \ldots\}$。

总可行区域 = $(\bigcup_{i} r_{1i}) \cap (\bigcup_{j} r_{2j})$
            = $\bigcup_{i,j} (r_{1i} \cap r_{2j})$

系统逐个检查每对配方的交集是否为空（是否冲突），只保留非空组合。

### 1.4 冲突检测与方案过滤

系统对每种配方组合做约束合取，检测典型冲突模式：

| 冲突类型 | 例子 | 结果 |
|:---|:---|:---|
| 等式矛盾 | DD+DE=4 与 DD+DE=6 | 不可行 |
| 范围矛盾 | 船数≤3 与 DD+DE=6 | 不可行（装不下）|
| 存在性矛盾 | 需 CL=1 与已选 6 艘无 CL 位 | 不可行 |

冲突的方案被过滤，可行的方案保留并展示。

### 1.5 路径先验约束：舰种过滤

**核心原则：路径一旦选定，可行空间即锁死。**

系统从所有可行配方的并集中，提取**出现过的舰种集合**，作为该路径下允许选择的舰种。未出现的舰种**直接不在界面中展示**，而非"展示但禁用"。

**示例**

路径 出击点 → A → E（阈值组合下）的可行配方可能为：
- 配方 X：船数=5，DD=4，CL=1
- 配方 Y：船数≤5，DD+DE=4，全高速

允许舰种 = {DD, CL, DE, 高速 BB, 高速 CA, 高速 CL...}

不允许舰种 = {CV, CVL, SS, AV, 低速 BB...} → **直接隐藏**

### 1.6 约束传播：数量调整的动态联动

用户在允许的舰种范围内调整数量，系统实时执行**约束传播（Constraint Propagation）**：

**维护状态**
- 当前已选舰种计数
- 剩余可行配方集（由当前各边阈值决定）

**每次操作后的传播逻辑**
1. 更新当前状态
2. 过滤剩余可行配方集：检查每个配方是否仍可能被满足
3. 若某个配方被排除，从候选集中移除
4. 根据剩余配方的并集，重新计算各舰种的 +/- 按钮状态
5. 若剩余配方唯一确定，锁定全部数量，不可再调

**按钮状态语义**
- **绿色高亮**：剩余所有可行配方都需要此舰种（强烈建议）
- **白色可用**：部分可行配方允许此舰种（可选）
- **灰色禁用**：当前状态下选择此舰种会导致所有配方不可行
- **红色警告**：已选数量超出任何配方的允许范围

**阈值调节对约束传播的影响**

用户调低某边阈值 → 该边新增配方进入候选 → 可能放宽其他边的联动限制。

> 例：边①原设 100%（仅 DD+DE=4），边②某配方需 CL=1。若用户将边①调到 70%（船数 1~3），则边②的 CL=1 配方可能因船数不足而冲突。系统实时反馈此变化。

### 1.7 死胡同与回退

若用户操作（包括调低阈值后仍无法兼容）导致剩余可行配方集为空，系统立即提示：

> ⚠️ 当前阈值与数量选择无法达成任何可行配方。
> 建议：撤销某步操作、调低某边阈值、或切换路径。

提供"重置"按钮，清零所有选择，恢复初始候选集。

### 1.8 与舰船库、舰队栏的联动

**三层界面联动结构**

| 区域 | 功能 | 约束来源 |
|:---|:---|:---|
| 左侧：舰种数量选择器 | 调整各舰种数量 | 路径先验过滤 + 约束传播 |
| 中间：舰船库 | 从已有舰娘中点选具体船只 | 左侧数量上限 + 舰种过滤 |
| 右侧：舰队栏 | 显示最终编成，可拖拽排序 | 总船数约束 + 旗舰位约束 |

**联动逻辑**
- 左侧数量确定后，中间舰船库自动切换到对应舰种标签页
- 某舰种数量选满后，该标签页显示"已选满"
- 右侧舰队栏槽位数由总船数约束决定（如船数=5 则 5 个槽）
- 拖拽排序时实时校验位置约束（如"旗舰需为 CL"）

## 功能二：编成给定 → 路径推演

用户在右侧面板配好舰队编成，系统在海图上正向推演所有可能路径，并标注每条边的概率。

### 2.1 特征提取

从编成中提取三类特征：
- 总船数 n ∈ [1,6]
- 舰种存在性（有无某类舰种）
- 舰种计数（各类舰种各几艘）

### 2.2 逐节点概率计算

从起点开始，对每个节点：
1. 用当前编成特征匹配该节点的规则表
2. 按优先级从高到低检查固定分支、概率分支、兜底随机
3. 计算每个出口的概率
4. 在海图对应边上标注概率值、着色

### 2.3 路径提取与总概率

从概率树中提取所有"根到叶"路径：
- 单条路径概率 = 路径上各边概率的乘积
- 到达目标节点的总概率 = 所有通往该目标的路径概率之和

### 2.4 海图视觉标注

| 概率范围 | 线条样式 | 含义 |
|:---|:---|:---|
| 100% | 绿色粗实线 | 确定可达 |
| 60%~99% | 黄色虚线 | 高概率可达 |
| 20%~59% | 橙色细虚线 | 低概率，看脸 |
| <20% | 红色细线 | 几乎不可达 |
| 0% | 灰色 | 当前编成下不可达 |

侧边栏列出所有可达路径及其总概率、期望战斗次数。

## 附录：约束类型汇总

| 类型 | 数学形式 | 示例 |
|:---|:---|:---|
| 总船数 | size = k / size ≤ k / size ≥ k | 船数=5，船数≤5 |
| 舰种存在 | type ∈ fleet / type ∉ fleet | 必须有 CL，不可有 CV |
| 舰种计数 | count(type_set) op value | DD=4，DD+DE≤4，CL≥1 |
| 旗舰约束 | flagship_type = T | 旗舰必须是 CL |
| 速力约束 | fleet_speed ≥ threshold | 全高速以上 |

## 附录：术语对照

| 术语 | 含义 |
|:---|:---|
| 配方 | 单条规则条目对应的完整约束组合 |
| 选择集 | 某节点某阈值下所有保留配方的并集 |
| 约束传播 | 根据当前选择实时缩小剩余可行空间 |
| 路径先验 | 路径确定后立即过滤不允许的舰种 |
| 正向推演 | 给定编成，计算可达路径与概率 |
| 反向求解 | 给定路径，反推所需编成约束 |
