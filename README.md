# Fleet Commander

海战战术模拟器 - 一个基于 HTML5 Canvas 的浏览器端海战策略游戏。

## 项目结构

```
fleet_commander/
├── frontend/          # 前端代码
│   └── index.html     # 主游戏页面（单文件应用）
└── README.md
```

## 玩法

1. **部署模式**：选择舰船类型，点击海面放置
2. **指挥模式**：选中舰船，滑动划出航路轨迹
3. **航母空袭**：拖拽航母到敌方目标发动空袭
4. **开始战斗**：点击「开始」进入自动战斗

## 技术栈

- 纯前端：HTML5 + CSS3 + Vanilla JavaScript
- 无外部依赖
- 单文件应用，直接打开 `frontend/index.html` 即可运行
